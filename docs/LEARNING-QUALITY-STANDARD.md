# Shared learning quality and mastery standard (11 October 2026)

Scope: DubboEwaste/AssetFlow, DCSPD, SupportOps Career Lab, AvancePD/AvanceProfessionalDevelopment and JoshHub Learning. This is a content-quality rubric, **not a certification or a finding about learner IQ**.

## Four stages (a module can move down if a link or assessment breaks)

1. **Orientation only:** one or more short introductions, prompts, or generic questions; may be appropriate for new volunteers but cannot claim deep subject competence.
2. **Developing:** topic-specific explanations + one useful original source or demonstration + a meaningful safe practice task. Questions must test subject knowledge rather than repeating the topic title, choosing the longest option, or selecting the obvious moral answer.
3. **Substantial:** prerequisites and meaningful depth; two independent teaching sources, ideally with text, figures, video or accessible transcript; **three** topic-specific worked cases including alternative hypotheses, model reasoning, meaningful failure modes, and a task the learner actually completes; at least one expert-level transfer challenge; explicit limitations.
4. **Mastery-ready:** substantial content PLUS instructor-reviewed competency criteria, verified performance on a fresh realistic case, feedback and a second attempt or spaced review. Live high-risk work requires suitable competent supervision, legal authorisation and local protocols. A self-ticked lesson or AI-graded quiz **never** proves mastery.

## Eight auditable dimensions (0 missing, 1 partial, 2 met)

- Accuracy and currency: direct reliable sources, dated external review, jurisdiction and product version declared.
- Conceptual depth: explanation of why/how, alternative causes, prerequisites and mechanisms.
- Diverse teaching: reading, visual or diagram, demonstrative video, accessible transcript/audio alternative; formats serve learning, not decoration.
- Worked examples: varied specific solved examples with reasoning rather than answer-only explanations.
- Deliberate practice: safe real/virtual tasks with materials, conditions, a concrete output and safety boundaries.
- Assessment quality: diagnostic entry check; recall, explanation, calculation/diagnosis, transfer case; no answer position/length cues; plausible misconceptions and reasoned feedback.
- Adaptive review: missed concepts are revisited, correct learners progress to harder tasks; spaced retrieval beyond same sitting.
- Observable evidence: recorded artefact, independent rubric feedback, repeat performance, and no false competence or certification claim.

Never rate module quality merely from the number of cards, videos, minutes or GitHub files. Prefer source-specific teaching over generated templates. Track what's delivered separately from what is proposed. For videos, use direct verified links rather than search links. If an audio source is missing, accessible written alternatives are acceptable, but report the audio gap.

## Release checks
- Every topic has stable ID, accurate name, owner/canonical source, primary guide and a stated stage.
- No missing/dead resource should be silently presented as verified. Automated URL checks are useful but insufficient for page/course relevance, paywalls or current legal effect.
- Audit assessment keys, option lengths, superficial distractors, unsafe advice and leakage of model answers before quizzes.
- Verify expected stage in the **actual deployed repository/branch**. Duplicate repositories or stale Vercel deployments must not be added as separate topics.
- Check responsive rendered pages, keyboard access, screen readers, save/resume and the logged-in learner path.
- Require learner work before reviewed completion; distinguish orientation progress from professional skill sign-off.

## Editorial worklist
1. Fix repeated template questions and irrelevant shared simulations, especially generated CompTIA Core 2 topics.
2. Fill source gaps and add **course-specific** diagrams, evidence tasks, case solutions and clearly labelled video/audio alternatives.
3. Map overlapping skill topics across AssetFlow, DCSPD, SupportOps, Avance and JoshHub rather than double-counting them.
4. Audit linked course pages and routes for usefulness, current availability and correct production environment.
5. Pilot independent grading on several fresh cases; log error patterns and revise teaching using actual learner errors (with privacy-safe data).

**Evidence rule:** Content inventory is a baseline. Only observed outcomes can establish mastery, and only authorised staff can grant operational permissions.
